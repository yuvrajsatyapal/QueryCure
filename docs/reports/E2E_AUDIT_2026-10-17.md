# QueryCure end-to-end AI investigation and functional audit — 2026-10-17

Scope: the whole product as a user meets it — the local profile, with Neon as the metadata DB (after `fcd0836`), the host-run worker, the Next.js web app, the real OpenRouter free models, and the local Docker benchmark sandbox. Everything below was run during this audit unless it is marked **not verified**. No secrets appear in this report.

## A. Overall readiness

**Verdict.** The core promise works end to end with a real model:
1. The user starts an investigation in the web app.
2. They watch the agents work live.
3. They approve the exact SQL.
4. The sandbox benchmarks the candidates with statistics.
5. A sealed, evidence-cited report states a verified recommendation.
6. Report replay re-verifies it byte for byte.

Two things keep this from being demo-ready:
- **The configured default model router (`openrouter/free`) cannot carry an investigation**: run 1 ended inconclusive.
- **The AI-written narrative can contradict the deterministic verdicts.**

Medians are in ms. Speed-up is baseline / candidate, with a 95 % bootstrap interval, from experiment `73db95e3`:

The result-row fingerprints matched the baseline on every arm and parameter set. The environment was PostgreSQL 17.11, arm64, `docker-relay`, `bench@2`. At sf = 0.1 the baseline is only ~3.8 ms; the absolute benefit is small, and the report says so ("materiality undetermined", see O4).

## E. Frontend audit (for the redesign phase)

1. **Missing integrations.**
   - No per-run model choice: the model can only be set as the default model of a BYOK key in Settings.
   - The Dashboard has no data (no recent runs, no pending approvals).
   - The experiment-replay comparison is reachable only through the replay page.
   - Mode B agent investigations are not prominent in the workspace flow (live EXPLAIN is).
2. **Status and progress.**
   - Long silent LLM periods: one free-model call took 25–120 s, a node up to ~8 min with retries, and the timeline shows nothing in between. Show "waiting for model (attempt n)" from the existing `llm_call` records.
   - Run-level reasons for inconclusive outcomes (O7).
3. **Truthfulness of display.**
   - The AI narrative must not contradict verdict badges (O2).
   - Hypotheses should reflect the verified candidate.
   - The "too noisy" caption must not appear on a verified row.
   - Version and approver formatting (O9).
4. **Confusing states.** "No hypotheses were produced" before synthesis has run; "Materiality undetermined" next to measured medians.
5. **Forms.** The New-investigation form shows the API's model setting, which can differ from the worker's actual model (`run.llm_model` is authoritative after start).
6. **Mobile.** No horizontal overflow at 375 px on the investigation page; the header overlap is fixed (F6). Long titles wrap to 4–5 lines at 375 px.
7. **Accessibility.** The axe e2e suite passes on 7 routes plus the empty states, keyboard focus and reduced motion.

## F. Deployment readiness (restricted public demo)

Blockers:
1. **Model reliability (O1).** Pin a capable free model, with the router only as a fallback. On the demo, users bring their own key (BYOK), so its default model must be one that produces valid structured output.
2. **Narrative honesty (O2).** A public report that recommends an unverified action next to a "Verified recommendation" heading undermines the product's core claim.
3. **OAuth end-to-end sign-in** on real HTTPS origins. Neither provider has completed a sign-in yet; the redirect URIs must be registered for the production `PUBLIC_API_URL`.
4. **Hosting decision and region.** The API must be always-on (SSE plus the embedded worker), in the Neon region (O11).
5. **Operational hygiene before go-live.**
   - Set `SANDBOX_IMAGE_DIGEST` and the git SHA (O10).
   - Schedule the retention job with `DATABASE_RETENTION_URL`.
   - Choose a `METRICS_TOKEN`.
   - Keep `FEATURE_SANDBOX=false` (prerecorded benchmarks only).

Not blockers: the sandbox is local-only by design (DEPLOYMENT §3); demo benchmarks are prerecorded and labelled.
